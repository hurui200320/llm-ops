# Notes

This folder contains chronological, diary-style notes (`# YYYYMMDD ...`) recorded while experimenting with models and inference engines. New findings, tuning runs, and upgrades are appended with dates rather than overwriting earlier entries.

## Note

Software changes very quickly, so conclusions in earlier entries may be superseded by later dated entries.
These notes are for reference only; see the `README.md` files under `deploy/`, `bench/`, and `scripts/` for the current operational state.
