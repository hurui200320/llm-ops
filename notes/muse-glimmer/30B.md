Feels like Gemma 4, talks like Gemma 4, even Gemma 4's jailbreak system prompt works!
Meta said this model is distilled from their Muse Spark, but I'd say it is similar to Gemma 4.

MTP: `--spec-type draft-dflash --spec-draft-n-max 2`

The maximum context size is 131072, which is not enough for coding or some long-horizon agentic work, but it is fast!
And unlike Gemma 4, it does not require much VRAM for context!

Also unlike Gemma 4, it does not use bidirectional attention for images, so the ubatch size can be smaller than the image token count.

I can use `np=4, ctx=524288`, serving 4 requests at once, each with the full context window.
