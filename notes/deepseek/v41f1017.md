# 20261025 First deploy (Strata dsv41, IST-DAS 2.00 bpw, 256K)

DeepSeek-V4.1-Flash-1017 on the 2× RX 7900 XTX pair through Strata's own `strata-dsv41` engine
(gfx110x build in the llm-ops image). Model: IST-DASLab IQ2_XXS 2.00 bpw (138 GB) + the 111 GB
Engram n-gram table (read from the NVMe) + the 8 GB DSpark drafter (auto: unloaded). Context 256K
(262144), RAM store `ssd-cache=40` (decimal GB). Deploy record, pins and the discovery fix:
[notes/strata.md](../strata.md), "DeepSeek-V4.1-Flash lane (dsv41)".

Engine placement on this box: `--tp 2` demoted to a layer split (IQ2_XXS expert blocks cannot split
across two cards), CUDA0 layers 0-20 / CUDA1 21-39, 4,353 of 15,360 experts (37.9 GB) in VRAM,
11,007 (94.9 GB) on the CPU lane, 16 threads. DSpark off (auto). At rest ~39 GiB RAM used,
~22-23 GiB available; during the 85 % calibration prefill available fell to ~15.5 GiB with swap
peaking at ~4.0 GiB (baseline 1.6 GiB).
